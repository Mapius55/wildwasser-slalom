# Wildwasser Slalom

Kanu-Slalom aus der Sicht des Paddlers, direkt im Browser: Slalom-Rennen, Kayak Cross, Freifahrt und Lernmodus auf echten und erfundenen Wildwasserstrecken.

**Spielen:** https://mapius55.github.io/wildwasser-slalom/

- Läuft auf dem Computer (Tastatur, Maus oder Gamepad) und auf dem Handy (Touch, auch iPhone).
- Zusammen spielen: im Menü «Zusammen spielen» öffnen und den Link teilen. Wer die Seite gleichzeitig offen hat, sieht die anderen Boote auf dem Wasser. Dafür werden Name, Farbe und Position über einen öffentlichen Relay-Server gesendet; Bestzeiten und Einstellungen bleiben nur in deinem Browser.
- Auf dem Handy über «Zum Home-Bildschirm» als App ablegen.

Alles steckt in `index.html` (mit three.js r128, MIT-Lizenz).
